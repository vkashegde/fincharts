# fincharts example

Demonstrates the `fincharts` package: all five chart types, dark/light
theming, pan/pinch-zoom/crosshair/tooltip interaction, the controller API,
a **realtime feed** page that simulates ticks and new bars via `CandleSeries`,
and a performance page for 1,000 / 10,000 / 50,000-candle data sets.

See the [root README](../README.md) for the package itself.

## Run

```bash
flutter pub get
flutter run
```
