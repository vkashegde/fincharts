# fincharts example

Demonstrates the `fincharts` package: all five Week-1 chart types, dark/light
theming, pan/pinch-zoom/crosshair/tooltip interaction, the controller API,
and a performance page for 1,000 / 10,000 / 50,000-candle data sets.

See the [root README](../README.md) for the package itself.

## Run

```bash
flutter pub get
flutter run
```
